# FocusDeck 1.12.0 — glow, sounds, landscape and developer preview

Android versionCode 17; Android/desktop 1.12.0. Application ID remains `com.hax.focusdeck`; session/report and achievement command contracts are unchanged. Work is local on `codex/glow-sounds-preview`, without GitHub pushes or phone installation.

## What changed

1. **Achievement-page glow:** the thick ring has a stronger static radial halo and layered strokes. The icon stays inside the ring. The extra icon before each card title is removed. Progress arcs remain grounded in stored percentages; streak-only full rings are decoration, not percentages.
2. **Detail glow and sparkles:** detail rings are larger, with a short opening bloom and nine orbiting/twinkling star/dot accents. The 2.4-second sparkle animation stops and leaves the static halo. Full enables it; Reduced/Off and Android animation scale zero suppress it. No permanent decorative animation or frame-time persistence.
3. **Landscape scrolling:** Overview and the archive/layout controls now live inside each category's lazy grid as a full-width item. A large Overview no longer consumes the height above the only scrollable card area. Category tabs/swipes, card sizes, reorder/archive/restore/delete, real measurements, and inline detail history remain.
4. **Sounds:** menu → Sounds offers separate Timer clock, Stopwatch clock, Buttons & navigation, and Completion & overtime choices. Four original clock samples (soft, mechanical, wood, digital) plus soft click, chime and bell are bundled. These deterministic PCM assets are generated by `scripts/generate-sounds.py` and covered by the project MIT license. Samples are predecoded with SoundPool. UI feedback covers taps in the main activity, including navigation and timer/card actions. It is not a replacement for every Android system/dialog interaction.
5. **Developer mode:** enable Display settings → Developer mode, Save, then menu → Developer preview. This opens an isolated, temporary achievement ledger with the same production card/detail/statistics renderer. Nothing is written into the real achievement store, reports, pairing or LAN snapshots.

## Sound controls

- Tick/UI choices default to Off. Existing boundary-sound enable/disable is retained; its default sample becomes Chime. Save applies the chosen media-volume gain, including zero mute.
- Tick clips play once per second only in the active phase, including countdown overtime. Pause/ready/between/reward/completed/stopped phases stop the tick stream. Countdown and stopwatch have independent selections. Disconnecting LAN does not itself change the active timer or chosen sound.
- Tick playback is independent of measured durations and display FPS. It never updates timer state, rewards, reports or the database on audio ticks. Scheduling/audio output depends on device power/audio policy; it is not a timing measurement source.
- Choose File uses the Android audio document picker and copies the selected bytes into private app storage. No broad storage permission or ADB transfer is needed.
- Custom clips: at most 2 MiB; clock duration up to 1 second, feedback up to 2 seconds; mono/stereo at ≤48 kHz. The file must have a supported audio track and pass native SoundPool decoding before selection is accepted. Invalid files show an error. Imports run off the UI thread, with asynchronous decoding.
- Preview plays the draft selection; Save persists it; Cancel leaves saved settings. Cancelled/replaced samples are cleaned from private storage when the dialog closes. A saved clip remains usable after the original device file moves or disappears. Reboot restores selections; SoundPool loads them again when used.
- Sound choices, volume and developer mode are phone settings, not new GPT/CLI command fields. Full/Reduced/Off visual motion does not force audio settings.

## Developer preview controls

- **Create card:** set a title, category, STREAK_ONLY / PROGRESS_ONLY / STREAK_AND_PROGRESS, current streak (0–90 days), completed streak lengths (comma-separated, up to 20, each 1–90 days), and current/total progress.
- **Samples:** replaces the sandbox with new-record, below-best, hybrid, completed-progress and fresh-start examples. Each has synthetic day/progress-history entries computed by the real statistics engine.
- **Edit Layout / card management:** size/reorder/archive/restore/delete act on this sandbox only.
- **Clear / Close:** discard the preview ledger. It is intentionally temporary and may reset across activity recreation. There is a 50-card cap.
- The preview banner and updated GPT instructions label this data synthetic. It is never evidence of real work, learning, mastery, streaks or reward eligibility.

## Upgrade and physical-device checks

Build from source on the existing PC checkout with the key used to sign the installed app. Keep `.git`, `android/local.properties`, signing keys, desktop settings/certificates/tokens and all history intact. Never uninstall or clear app data to bypass a signature mismatch.

```bash
cd /home/hax/Projects/FocusDeck
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export ANDROID_HOME="$HOME/Android/Sdk"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH"
bash scripts/build-android.sh test
bash scripts/build-android.sh debug
ADB_SERIAL=R3CX90NC7HR bash scripts/install-apk.sh
```
