# Session Complete orbital artwork

The built-in image-generation tool produced `android/app/src/main/res/drawable-nodpi/session_orbit_art.png` using Hax's cropped reference `docs/design/approved-session-orbit-detail.png`. It is an opaque grayscale background layer, not a screenshot of the app. No Python image editing was used. `ReferenceUi.ThemedArtwork` colors its luminance with the selected global accent, clamps near-black to OLED black and decodes/caches off the UI thread. `ReportScreen.CompletionOrbit` overlays the actual native ring/check or stopped-state mark.

Final prompt (built-in tool; stylized-concept): Production background artwork for an Android session-completed hero, composited under a native checkmark ring. Reference image guides lighting, materials and tilted orbit composition only. Opaque pure-black 1536 × 1024 landscape. Two small softly shaded spherical moons with subtle craters: left at 11% width / 47% height, diameter 7% height; right at 90% width / 60% height, diameter 5.5% height. Very faint thin diagonally tilted elliptical orbital arcs above/below an empty centered interior. Restrained soft atmospheric haze around the center, near-black inside radius 29% of height, fading to pure black at the edges. Strictly monochrome white/gray to allow native accent tint. Complete arcs and moons inside the canvas. No central ring, checkmark, text, metrics, UI, stars, extra planets or watermark.

Native hero: fit the complete artwork inside 260 × 174 dp and center a 128 dp HaloRing over it. Artwork is static; completed reports illuminate the live ring once, then settle. All actual report totals, titles and metric cards stay native. Actual pixel matching and phone rendering remain unverified.
